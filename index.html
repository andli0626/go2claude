Features

四个小设计，省掉一堆重复动作

它的目标很窄：把「打开 Finder → 定位项目 → 开终端 → 进目录 → 敲 claude」压成一次点击。其余一概不做。

一键定位当前目录

通过 AppleScript 读取最前面的 Finder 窗口路径，%PATH% 在启动前替换成真实路径——空格、中文目录名都照常工作。

  • 不用手动 pwd，窗口切到哪就进哪
  • 路径转义交给模板渲染层处理
  • 没有占位符时直接报错，不会误改目录

命令模板由你决定

模板存在本地偏好里，改一行就换行为。默认带跳过权限确认，开发时可以只切目录。

  • 默认：cd %PATH% && claude --dangerously-skip-permissions
  • 开发模式：cd %PATH% && claude
  • 也能换成任意 CLI 或本地脚本

两个 App，各管一段

Go2Claude 管设置与自检；Go2Claude Toolbar 只有一件事——在 Finder 里被点一下。

  • 拖进工具栏即可，随时可移除
  • 不常驻菜单栏、不占 Dock
  • 点完即退出，只留下 Terminal

先体检，再开跑

首次启动会检测 claude 是否在当前 shell 可用；缺失时弹安装指引，设置页也持续提示。

  • 未签名安装包附带放行说明
  • 自动化权限缺失时给出排查路径
  • 失败不会静默，错误可回看
How it works

一次点击，四步走完

按钮不接管你的工作流，只把该在哪个目录启动这件事替你做掉。

01

你在 Finder 里

打开任意文件夹窗口，切到要干活的项目目录。

Finder front window
02

点一下工具栏按钮

Go2Claude Toolbar 被点中，随即启动一次启动流程。

Toolbar helper
03

读取并渲染 %PATH%

取当前窗口路径，替换进命令模板，做 shell 转义。

CommandTemplateRenderer
04

交给 Terminal

新窗口执行命令，Claude 已在项目目录里待命。

TerminalLauncher

Setup

三步装进 Finder 工具栏

安装包不到 1 MB，不含安装脚本、不含后台服务。

1

安装

双击 .pkg 按提示完成；或解压 zip，把两个 .app 拖进「应用程序」。

Go2Claude.pkg
2

打开一次主程序

确认命令模板，点「查看如何添加到 Finder 工具栏」看具体操作。

open -a Go2Claude
3

拖进工具栏

按住 ⌘ 把 Go2Claude Toolbar.app 拖到 Finder 工具栏，松手即可。

⌘ + drag → Finder toolbar

首次点击会申请权限

macOS 会请求「自动化」权限（Finder 与 Terminal），允许后按钮才会生效。这是系统行为，不是应用在后台做事。

FAQ

常见问题

点开看答案；多数问题与 macOS 权限有关，不在应用本身。

打开时提示「无法验证开发者」怎么办？+
关闭弹窗，打开「系统设置 → 隐私与安全性」，在页面下方找到与 Go2Claude 相关的提示，点「仍要打开」，然后再次双击安装包或应用。
点了工具栏按钮没有反应？+
先在「隐私与安全性 → 自动化」里确认 Go2Claude 有 Finder 与 Terminal 权限；再确认主程序至少成功运行过一次。如果按钮指向的是旧版本 App，删除旧按钮后重新把新的 Go2Claude Toolbar.app 拖进工具栏。
提示找不到 claude？+
在终端执行 which claude，有输出说明已装好；若在应用内仍提示缺失，通常是 shell 环境不同，按弹窗里的官方文档链接重新安装 Claude CLI 后重启应用即可。
可以改成别的命令吗？+
可以。设置页直接编辑模板，保留 %PATH% 占位符即可。例如只切目录：cd %PATH%；或启动别的 CLI：cd %PATH% && open -a iTerm。改坏了点「恢复默认」。
Intel Mac 能用吗？+
可以。打包脚本默认做 arm64 + x86_64 通用构建，最低系统 macOS 13.0。
它会联网或上传我的代码吗？+
不会。应用只做两件事：读取当前 Finder 目录、在 Terminal 里执行你配置的命令。没有网络请求、没有统计上报、没有后台常驻。
