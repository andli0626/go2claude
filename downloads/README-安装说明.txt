Go2Claude 安装说明
=================

这是什么
--------
Go2Claude 是一个小工具，可以让你在 Finder 里更方便地打开当前文件夹，并启动本机已经安装好的 Claude CLI。

安装包里有什么
--------------
- Go2Claude.app：主程序
- Go2Claude Toolbar.app：可拖到 Finder 工具栏
- Go2Claude.pkg：安装包

系统要求
--------
- macOS 13 或更高版本
- Apple 芯片（M 系列）或 Intel Mac
- 本机已经安装 Claude CLI，并且终端里可以运行 `claude`

怎么安装
--------
1. 双击 `Go2Claude.pkg`
2. 按提示完成安装
3. 安装完成后，在“应用程序”里打开 `Go2Claude.app`

如果 macOS 提示“无法打开”或“无法验证开发者”
------------------------------------------
这是因为当前版本是未签名分发版本，属于正常现象。

可以这样处理：
1. 先关闭弹窗
2. 打开「系统设置」→「隐私与安全性」
3. 找到与 Go2Claude 相关的提示
4. 点击「仍要打开」或允许继续安装
5. 再次双击安装包或应用

首次运行会发生什么
------------------
- 程序会先检查你的电脑里有没有安装 Claude CLI
- 如果没有安装，会提示你去看安装说明
- 第一次连接 Finder 或 Terminal 时，macOS 可能会请求权限，请选择允许

怎么添加 Finder 工具栏按钮
--------------------------
1. 先打开 `Go2Claude.app`
2. 找到 `Go2Claude Toolbar.app`
3. 在 Finder 中按住 Command 键，把它拖到 Finder 工具栏
4. 以后点击这个按钮，就可以在当前 Finder 文件夹里启动

如果按钮还是旧版本，请先把旧按钮移除，再拖入新的 `Go2Claude Toolbar.app`。

提醒
----
- 这是非官方第三方工具
- 它会在你的电脑上调用 Terminal 并执行配置好的命令
- 使用前请确认你的命令模板内容是你自己认可的

祝你使用顺利。
