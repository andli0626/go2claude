## 1. 产品概述

### 1.1 产品定位

Go2Claude 是一款轻量级 macOS 实用工具，灵感来源于 Go2Shell。它允许用户在 Finder 工具栏添加一个按钮，点击即可在当前 Finder 文件夹中启动 Claude CLI，为开发者提供快速访问 AI 编码助手的便捷方式。

### 1.2 核心价值

- **效率提升**：一键从 Finder 当前目录进入 Claude CLI，无需手动切换目录
- **无缝集成**：深度集成 macOS Finder 工具栏，符合原生应用体验
- **灵活配置**：支持自定义命令模板，适应不同使用场景
- **零依赖**：纯 Apple 框架实现，无需第三方依赖

### 1.3 目标用户

- 使用 Claude CLI 的 macOS 开发者
- 需要频繁在不同项目目录间切换的开发者
- 习惯使用 Finder 进行文件管理的用户

### 1.4 产品范围

**包含功能**：
- Finder 工具栏按钮集成
- 当前 Finder 路径自动获取
- Terminal.app 自动启动并执行命令
- 命令模板配置界面
- 命令模板持久化存储
- Shell 路径自动转义

**不包含功能**：
- Windows/Linux 平台支持
- 其他终端应用支持（仅支持 Terminal.app）
- 云端配置同步
- 多语言界面（仅中文）

## 2. 核心功能需求

### 2.1 Finder 工具栏集成

#### 2.1.1 功能描述
允许用户将 Go2Claude.app 添加到 Finder 工具栏，实现一键启动。

#### 2.1.2 用户流程
1. 用户运行 Go2Claude 应用
2. 点击「查看如何添加到 Finder 工具栏」按钮
3. 在 Finder 中选择 Go2Claude.app
4. 按住 Command 键拖动到 Finder 工具栏
5. 之后在任何 Finder 窗口中点击该按钮即可启动

#### 2.1.3 验收标准
- [ ] 按钮可成功添加到 Finder 工具栏
- [ ] 点击按钮可触发应用启动
- [ ] 按钮图标正确显示
- [ ] 按钮在所有 Finder 窗口中可见

### 2.2 当前 Finder 路径获取

#### 2.2.1 功能描述
通过 AppleScript 自动获取当前 Finder 窗口的前端路径。

#### 2.2.2 技术实现
使用 AppleScript 获取 Finder 前端窗口的目标路径：
```applescript
tell application "Finder"
    get target of front window as alias
end tell
```

#### 2.2.3 异常处理
- **无 Finder 窗口打开**：显示错误提示"没有找到已打开的 Finder 窗口，请先打开一个文件夹后再试。"
- **AppleScript 执行失败**：显示具体错误信息并打开配置窗口

#### 2.2.4 验收标准
- [ ] 能正确获取当前 Finder 窗口路径
- [ ] 支持包含空格的路径
- [ ] 支持包含中文字符的路径
- [ ] 支持包含特殊字符的路径
- [ ] 无窗口时显示友好错误提示

### 2.3 命令模板渲染

#### 2.3.1 功能描述
将用户配置的命令模板中的 `%PATH%` 占位符替换为实际的 Finder 路径，并进行 Shell 转义。

#### 2.3.2 占位符规则
- 必须包含 `%PATH%` 占位符
- `%PATH%` 会被替换为当前 Finder 窗口路径
- 路径会进行 Shell 转义（单引号包裹，内部单引号转义）

#### 2.3.3 默认模板
```
cd %PATH% && claude --dangerously-skip-permissions
```

#### 2.3.4 开发模式模板
```
cd %PATH% && claude
```

#### 2.3.1 验收标准
- [ ] 正确替换 `%PATH%` 占位符
- [ ] 路径包含空格时正确转义
- [ ] 路径包含单引号时正确转义
- [ ] 缺少占位符时显示错误提示
- [ ] 支持自定义命令模板

### 2.4 Terminal 启动

#### 2.4.1 功能描述
在 Terminal.app 中执行渲染后的命令。

#### 2.4.2 技术实现
使用 AppleScript 启动 Terminal 并执行命令：
```applescript
tell application "Terminal"
    activate
    do script "command"
end tell
```

#### 2.4.3 Shell 检测
自动检测用户当前使用的 Shell：
- 优先使用 `getpwuid(getuid())` 获取用户 Shell
- 默认回退到 `/bin/zsh`

#### 2.4.4 验收标准
- [ ] Terminal.app 成功启动
- [ ] 命令在 Terminal 中正确执行
- [ ] Terminal 窗口获得焦点
- [ ] 支持用户自定义 Shell（zsh/bash 等）

### 2.5 配置管理

#### 2.5.1 功能描述
提供图形化界面配置命令模板，支持持久化存储。

#### 2.5.2 配置项
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| commandTemplate | String | `cd %PATH% && claude --dangerously-skip-permissions` | 命令模板 |

#### 2.5.3 存储方式
使用 UserDefaults 持久化存储，键名为 `commandTemplate`。

#### 2.5.4 配置界面功能
- 命令模板编辑框
- 恢复默认按钮
- 切换开发模式按钮
- 立即打开 Claude 按钮
- 使用说明按钮
- 实时验证 `%PATH%` 占位符

#### 2.5.5 验收标准
- [ ] 配置可正确保存到 UserDefaults
- [ ] 应用重启后配置保持不变
- [ ] 恢复默认按钮可重置为默认模板
- [ ] 切换开发模式按钮可切换为开发模板
- [ ] 缺少占位符时显示红色警告

### 2.6 启动模式

#### 2.6.1 功能描述
支持通过命令行参数指定不同的启动模式。

#### 2.6.2 启动模式
| 模式 | 触发方式 | 行为 |
|------|----------|------|
| 正常模式 | 无参数或点击工具栏按钮 | 获取 Finder 路径并启动 Terminal |

#### 2.6.3 验收标准

- [ ] 参数不区分大小写

| 角色 | 描述 | 典型需求 |

### 4.2 使用场景

**前置条件**：
- 已安装 Claude CLI
- 已将 Go2Claude 添加到 Finder 工具栏

**操作步骤**：
1. 在 Finder 中导航到项目目录

4. 点击「立即打开 Claude」测试

**预期结果**：
- 配置窗口正常显示
- 命令模板可编辑
- 配置自动保存
- 测试按钮可验证配置

1. 在包含空格的目录中点击 Go2Claude 按钮

**预期结果**：
- Terminal 正确打开
- 路径被正确转义
- 命令成功执行

#### 场景 4：无 Finder 窗口时启动

**前置条件**：
- 没有打开的 Finder 窗口

### 6.1 配置数据

| 字段名 | 类型 | 存储位置 | 默认值 | 说明 |
|--------|------|----------|--------|------|
| commandTemplate | String | UserDefaults | `cd %PATH% && claude --dangerously-skip-permissions` | 命令模板 |

### 6.2 运行时数据

| 字段名 | 类型 | 作用域 | 说明 |
|--------|------|--------|------|
| launchMode | LaunchMode | 应用生命周期 | 启动模式（normal/config） |
| finderPath | String | 启动流程 | 当前 Finder 窗口路径 |
| renderedCommand | String | 启动流程 | 渲染后的完整命令 |
| launchMessage | String? | 配置窗口 | 启动错误消息 |

### 6.3 枚举类型

#### LaunchMode
```swift
enum LaunchMode {
    case openCurrentFinderPath  // 正常模式
    case configuration           // 配置模式
}
```

#### LaunchResult
```swift
enum LaunchResult {
    case terminate              // 成功启动，退出应用
    case openSettings(message: String?)  // 失败，打开配置窗口
}
```

## 9. 技术架构

### 9.1 架构分层

```
┌─────────────────────────────────────────────────────────────┐
│                      Go2Claude 应用层                       │
│  (main.swift → AppDelegate → SettingsWindowController)     │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     AppCoordinator 协调器                    │
│        (编排: LaunchMode + Settings + 核心组件)             │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│FinderPathResolver│  │CommandTemplate │   │TerminalLauncher│
│   Finder路径解析 │   │  命令模板渲染  │    │  Terminal启动  │
└───────────────┘    └───────────────┘    └───────────────┘
```

### 9.2 核心模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| AppCoordinator | 编排启动流程 | AppSettings, FinderPathResolver, CommandTemplateRenderer, TerminalLauncher |
| AppSettings | 配置管理 | UserDefaults |
|| LaunchMode | 启动模式解析 | 无 |
| CommandTemplateRenderer | 命令模板渲染 | 无 |
| FinderPathResolver | Finder 路径获取 | AppleScriptRunner |
| TerminalLauncher | Terminal 启动 | AppleScriptRunner, UserShell |
| AppleScriptRunner | AppleScript 执行 | NSAppleScript |

### 9.3 设计模式

| 模式 | 应用位置 | 用途 |
|------|----------|------|
| 依赖注入 | AppCoordinator | 通过协议注入实现可测试性 |
| 协议抽象 | FinderPathResolving, TerminalLaunching | 解耦实现 |
