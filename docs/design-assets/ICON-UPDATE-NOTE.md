## 🎨 设计特点

### 字母标识
**C2G** = **C**yan **2** **G**radient 的缩写，也代表 **Go2Claude** 的视觉化

### 配色方案
```
渐变：#00f0ff → #0066ff → #a855f7
      (青色)    (蓝色)     (紫色)

背景：#1e1e3f → #0a0a14 → #1a1a2e
      (深蓝灰渐变)
```

### 视觉效果
- ✅ 青蓝紫三色流畅渐变
- ✅ 深色背景带中心光晕
- ✅ 三个小火花装饰（左上、右上、底部）

- ✅ 现代简洁风格
