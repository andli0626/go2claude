# 图标相似度验证清单

## 参考图片元素分析

根据用户提供的图片，需要匹配的元素：

### 必需元素（权重分配）
1. **G2C 字母** (40%)
   - 字母形状：G、2、C
   - 渐变方向：左→右（绿→蓝→紫）
   - 字体粗细：Bold/Black
   - 位置：水平居中

2. **三个装饰圆点** (30%)
   - 左上角：蓝色圆点
   - 右上角：紫色圆点
   - 底部中央：绿色圆点（较小）

3. **底部绿色线条** (20%)
   - 位置：G2C 下方
   - 颜色：绿色渐变
   - 形状：圆角矩形

4. **背景** (10%)
   - 颜色：深色（接近黑色）
   - 形状：macOS Squircle

## 当前版本 V3 对照

- [ ] G2C 字母是否正确渲染
- [ ] 渐变方向是否正确
- [ ] 三个圆点位置是否精确
- [ ] 底部线条是否存在
- [ ] 背景颜色是否匹配

## 需要验证的点

由于之前渲染出现了问题（显示为 ODA 或其他字母），需要确认：
1. SVG 中的文字是否能正确转换为路径
2. rsvg-convert 渲染是否正确
3. 是否需要将文字转为路径

## 如果需要调整

如果相似度不足 95%，需要：
1. 将 G2C 文字转换为路径（避免字体问题）
2. 精确调整圆点位置
3. 调整渐变角度和颜色
