# Go2Claude 应用图标设计文档

## 📐 设计规格

### macOS 图标规范（2024-2025）
- **画布尺寸**: 1024x1024px
- **实际内容**: 824x824px（居中，留出透明边距）
- **圆角半径**: 185.4px（macOS Big Sur+ 统一 squircle 形状）
- **输出格式**: PNG-24 with Alpha（透明背景）

## 🎨 设计理念

### 核心概念
**Go2Claude** = **终端（Terminal）** + **AI 智能（Intelligence）** + **快捷启动（Quick Launch）**

### 视觉元素
1. **深色渐变背景** (#1E293B → #0F172A)
   - 代表开发者工具的终端本质
   - 符合 macOS 暗色模式生态

2. **命令提示符符号** (`>_`)
   - 绿色 (#22C55E) - 代表命令执行成功
   - 简洁的 Chevron 箭头 + 下划线光标

3. **AI 火花元素** (✨)
   - 蓝色 (#3B82F6) - 代表人工智能
   - 位于右上角，象征智能化增强

4. **材质分层效果**
   - 玻璃质感高光（左上角）
   - 边缘光晕（蓝色 AI 光晕）
   - 内发光（绿色终端光晕）

## 🔧 使用说明

### 在 Xcode 中使用
1. 打开 `Go2Claude.xcodeproj`
2. 在 Project Navigator 中找到 `Resources` → `AppIcon.appiconset`
3. 图标已自动配置，无需手动导入
4. 构建时会自动打包到 `.app`  bundle

### 重新生成图标
如需修改设计，运行:

./generate-icons.sh

## 📝 设计决策记录

### 为什么选择深色主题？
1. **开发者偏好**：开发者工具普遍采用暗色主题
2. **终端传统**：命令行界面传统上是黑底绿字
3. **macOS 生态**：与 macOS 暗色模式完美融合
4. **AI 科技感**：深色背景更能突出 AI 光效

### 为什么使用 Chevron 符号而不是完整终端窗口？
1. **简洁性**：小尺寸下更易识别
2. **象征性**：`>_` 是终端的通用符号
3. **差异化**：与 Go2Shell 的文件夹图标区分
4. **聚焦核心**：强调"命令行"而非"文件夹"

### 为什么添加 AI 火花？
1. **产品定位**：Go2Claude 是 AI 助手，不是普通终端
2. **视觉平衡**：右上角火花平衡左下角命令符
3. **品牌识别**：蓝色 AI 光成为品牌标识
4. **现代感**：符合 2025 macOS 图标材质分层趋势
