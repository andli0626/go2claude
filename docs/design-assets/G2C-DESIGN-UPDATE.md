## 🆕 G2C 设计理念

### 核心概念
**G2C** = **Go 2 Claude** 的缩写，直接传达品牌名称

### 设计元素解读

#### 1. **G2C 字母组合**
- **字体风格**: 自定义几何无衬线字体
- **渐变效果**: 绿 → 蓝 → 紫 三色渐变
  - 绿色起点 (#22C55E): 代表终端/命令行
  - 蓝色中点 (#3B82F6): 代表 AI 智能
  - 紫色终点 (#8B5CF6): 代表创造力/魔法
- **发光效果**: 绿色光晕，增强科技感

#### 2. **布局结构**
```
┌─────────────────────┐
│  ✨              ✨  │
│                     │
│      G  2  C        │
│                     │
│        _____        │
│                     │
└─────────────────────┘
```

- **G2C 居中**: 视觉焦点
- **底部下划线**: 终端光标符号（____）
- **三个火花**: 顶部左/右 + 底部，形成三角平衡

#### 3. **配色升级**

| 元素 | 旧版本 | G2C 版本 | 含义 |
|------|--------|----------|------|
| 主符号 | 绿色 | 绿→蓝→紫渐变 | 终端→AI→魔法 |
| 背景 | 深灰 | 深灰（保持不变） | 开发者工具本质 |
| 光晕 | 蓝色 | 蓝色（保持不变） | AI 智能 |
| 火花 | 蓝色 | 蓝+紫+绿 | 多元智能 |

## 📐 G2C 设计规范

### 字体设计
- **G**: 开口向右，象征开放性和连接
- **2**: 数字形态，象征技术/代码
- **C**: 闭合圆弧，象征完整/闭环

### 间距比例
```
G : 2 : C = 1 : 0.9 : 0.95
字间距：15% 字母宽度
整体宽度：画布的 45%
整体高度：画布的 30%
```

### 渐变规范
```css
/* G2C 渐变定义 */
background: linear-gradient(
  135deg,
  #22C55E 0%,    /* 终端绿 */
  #3B82F6 50%,   /* AI 蓝 */
  #8B5CF6 100%   /* 魔法紫 */
);
```

### 发光效果
```css
/* G2C 光晕 */
filter: drop-shadow(0 0 20px rgba(34, 197, 94, 0.6));
```

## 🎨 色彩心理学解读

### G2C 渐变的三重含义

1. **绿色 (#22C55E)**
   - 终端/命令行的传统色彩
   - 成功/执行的象征
   - 开发者文化的体现

2. **蓝色 (#3B82F6)**
   - AI/智能的代表色
   - 专业/可信的感觉
   - 科技感最强

3. **紫色 (#8B5CF6)**
   - 魔法/创造力的象征
   - AI 的"神奇"特质
   - 区别于普通工具

**渐变顺序**: 从"终端工具" → "AI 智能" → "创造魔法"

## 🎯 设计决策

### 为什么选择 G2C 而不是完整 "Go2Claude"？
1. **空间限制**: 图标尺寸小，长文字难以识别
2. **记忆点**: 缩写更容易记忆和传播
3. **视觉简洁**: 3 个字符在小尺寸下仍清晰
4. **品牌延伸**: G2C 可衍生出子品牌（如 G2C-Pro, G2C-Enterprise）

### 为什么使用渐变而不是纯色？
1. **现代感**: 渐变更符合 2025 设计趋势
2. **故事性**: 渐变色讲述"终端→AI→魔法"的故事
3. **视觉吸引力**: 渐变更生动，不单调
4. **差异化**: 与单色图标形成差异

### 为什么添加下划线？
1. **终端符号**: 光标闪烁的象征
2. **视觉平衡**: 底部元素平衡 G2C 的重量
3. **功能暗示**: 暗示"输入/命令"的交互
